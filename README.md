# Macintosh XCode formatter
C++ PMString debugger formatter for InDesign 2026

## Using lldb formatter by Python

1. Add .lldbinit to your home directory

2. Create an lldb folder in your home directory

3. Add indesign_formatters.py to the lldb folder

4. Restart XCode
